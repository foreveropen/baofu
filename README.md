# 30秒暴富挑战 · 手速印钞小游戏

一个 30 秒狂点按钮印钞票的无脑爽游。手速越快赚越多，结束后生成一张可截图炫耀的"身价卡"，天生适合发群比手速。

## 在线试玩

https://foreveropen.github.io/baofu/

## 玩法

- 点击「印钞！」按钮（或按空格）疯狂印钱
- 手速超过 7/11/15 次/秒，连击倍率升到 x2 / x3 / x5
- 屏幕随机弹出金色钞票，点中 +¥50 暴击
- 30 秒到点结算，根据总金额给你一个爆笑称号

## 称号表

| 金额 | 称号 |
|---|---|
| <100 | 街头乞丐 |
| 100-250 | 打工人 |
| 250-450 | 万元户 |
| 450-700 | 小老板 |
| 700-1000 | 企业主 |
| 1000-1500 | 富商巨贾 |
| 1500+ | 首富继承人 |

## 技术要点

- 零依赖单 HTML 文件，Canvas 渲染粒子/飘字
- WebAudio 合成音效，无外部资源
- 结算页自动生成 560×700 炫耀图，一键下载 PNG
- 桌面鼠标 + 手机触屏 + 空格键盘三端统一操作
